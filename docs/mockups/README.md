# Mockupi

Mockupi glavnih dijelova interfejsa postoje u prijavi teme. Tokom implementacije interfejs ce se razvijati u skladu sa prihvacenim funkcionalnostima i pravilima za desktop i mobilni dio aplikacije.

## Planirani desktop mockupi

- Upravljanje terminima
- Upravljanje rezervacijama
- Upravljanje proizvodima
- Upravljanje narudzbama
- Upravljanje galerijom
- Upravljanje novostima
- Upravljanje cjenovnikom
- Upravljanje historijom
- Generiranje izvjestaja

## Planirani mobilni mockupi

- Pregled naslovne strane
- Rezervacija termina
- Moje rezervacije
- Pregled trgovine i proizvoda
- Moja korpa
- Pregled galerije
- Ocjenjivanje usluge
- Moje narudzbe
- Profil korisnika
- Notifikacije
